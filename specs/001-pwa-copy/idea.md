## Формулювання (одним реченням)

Український читач англомовних книжок отримує той самий English Reader як PWA, яку можна відкрити й установити на iPad (а також на інших пристроях) без Xcode, підпису й перевстановлення через кабель, щоб читати з паралельним перекладом, картками слів, озвученням і тренуванням слів так само, як у нативному застосунку.

| | |
|---|---|
| **Проблема** | Нативний застосунок живе лише на одному iPad, що підписаний через Xcode: оновлення потребують Mac, кабелю й перепідпису (безкоштовний профіль — кожні 7 днів), а на інших пристроях застосунку немає. |
| **Для кого** | Той самий користувач (рівень B1–C1, читає англійські книжки українською мовою інтерфейсу) на iPad у Safari, а додатково — на iPhone, Android, Mac/ПК у браузері. |
| **Бажана зміна** | Одна адреса HTTPS → «На початковий екран» → застосунок з тими самими екранами, жестами, налаштуваннями, ШІ-перекладом і озвученням; оновлення без Xcode. |
| **Користь** | Немає залежності від Xcode й терміну дії підпису; один код для всіх платформ; швидкі оновлення; основа для подальшої розробки без Mac. |

## Що означає «точна копія»

Копіюється **поведінка й вигляд, видимі користувачеві**, за станом нативного застосунку після етапу 2.5:

- екрани: бібліотека, читалка, бічна панель (Налаштування / Зміст / Збережене), картка слова, екран «ШІ-сервіси», «Керування словниками», «Збережене», тренування (налаштування, ознайомлення, вправи 1–5, підсумок);
- усі тексти інтерфейсу українською — дослівно з Swift-коду;
- ті самі моделі OpenAI, системні промпти, JSON-схеми, ключі кешів і типові значення налаштувань;
- ті самі жести (G1–G8, X1–X8), пороги (0,5 с, 10 pt, автоприховування в рядках), діапазони й кроки параметрів (B1–B7, PT, DT, A1–A6);
- ті самі алгоритми: розбиття на речення, імпорт EPUB/TXT/MD, вибір набору тренування, обманки, рівні та інтервали повторення.

Що неможливо скопіювати через обмеження вебплатформи, перелічено нижче в «Оцінці відмінностей» і в `spec.md` → «Свідомі відхилення».

# 2. Оцінювання

## За

- Уся «інтелектуальна» частина — HTTP-запити до OpenAI (Chat Completions у JSON-режимі й `/v1/audio/speech`). API OpenAI дозволяє виклики з браузера (CORS), тому промпти, схеми й кеші переносяться 1:1.
- Імпорт написано вручну без системних бібліотек (власний ZIP-читач, толерантний HTML-сканер, регулярні вирази для TXT/MD) — алгоритми переносяться в TypeScript майже рядок у рядок.
- Типографіка в браузері **простіша**, ніж у SwiftUI: вирівнювання за шириною (`text-align: justify`), відступ першого рядка (`text-indent`), міжрядковий інтервал — стандартні CSS-властивості; у нативному застосунку для них знадобився власний `TextRenderer`.
- Кожне слово як окремий DOM-елемент дає точне визначення слова й речення під пальцем без ручної карти прямокутників.
- Шрифти списку B1 (New York, SF Pro, Georgia, Charter, Iowan Old Style, Palatino, Baskerville) є в iPadOS і доступні Safari — на iPad текст виглядатиме так само.
- Є 82 тести як готові сценарії перевірки.
- Апаратна клавіатура в Safari віддає Esc, Return, цифри — частина обмежень XCUITest зникає.

## Проти / витрати

- Обсяг: орієнтовно 8–10 тис. рядків TypeScript/TSX/CSS + ~3 тис. рядків тестів; 6 хвиль завдань (див. `tasks.md`), реалістично 4–6 робочих сесій агента.
- Потрібен хостинг HTTPS (service worker, мікрофон і встановлення працюють лише на HTTPS або `localhost`). Безкоштовні варіанти: Cloudflare Pages, Netlify, GitHub Pages (для приватного репозиторію Pages платні). Розгортання — зовнішня дія, потребує окремого дозволу.
- Платні живі тести OpenAI — як у нативному проєкті, ~$0,01–0,05 за прогін, лише з дозволом.
- Нативні системні елементи (навігаційна панель, аркуші з detents, перемикачі, контекстні меню, SF Symbols) потрібно відтворити вручну.

## Альтернативи

- **Залишити лише нативний застосунок і купити Apple Developer Program ($99/рік)** — знімає 7-денний підпис і дає TestFlight, але не дає інших платформ і досі потребує Mac для збірки. Відкинуто як основний шлях: користувач просить саме PWA.
- **Capacitor/обгортка PWA в нативний контейнер** — повертає Keychain, фоновий звук і офлайн-переклад Apple через плагіни, але знову потребує Xcode й підпису. Можливий наступний етап поверх тієї самої кодової бази PWA.
- **Власний сервер-проксі для OpenAI** — ховає ключ від браузера, але додає хостинг бекенда, автентифікацію й витрати. Не входить до цього проєкту: копія зберігає модель «власний ключ користувача».

## Оцінка відмінностей PWA від нативного застосунку

Оцінка за функціональними групами `task_01.md`. «Паритет» — частка поведінки, видимої користувачеві, яку можна відтворити так само на iPad у Safari (установлена PWA, iPadOS 17+).

| Група (ID у task_01.md) | Паритет | Що буде інакше |
|---|---|---|
| Бібліотека, імпорт EPUB/TXT/MD, демо-книжка (R1) | ~95 % | Вибір файлу через системне вікно «Файли» так само; контекстне меню «Видалити» — власне, без системного розмиття. |
| Читання, розділи, зміст, позиція (R2, R6) | ~98 % | Позиція так само зберігається за абзацом. |
| «Текст книги»: шрифти, розмір, інтервали, поля, вирівнювання (B1–B7) | ~100 % на iPad | На Android/Windows немає частини шрифтів — найближча заміна. Вирівнювання за шириною браузер робить сам (з переносами — навіть краще). |
| Паралельний переклад, панель, автоприховування (P1–P6, A1–A6, PT1–PT5) | ~95 % | Поріг рахується в CSS-пікселях (на iPad 1 pt = 1 CSS px). |
| Жести речення/слова/довгого натискання (G1–G8) | ~90 % | Відчуття довгого натискання може трохи відрізнятися; потрібне придушення системного виділення Safari. |
| Виділення фрагмента (X1–X8) | ~85–90 % | Власна реалізація без системної лупи. |
| ШІ-переклад, картка слова, рівень, форми, «Пояснити детальніше» (R7, DT3–DT6) | 100 % | Ті самі запити, промпти, кеші. |
| Офлайн-резерв Apple (F1–F7) | 0 % | Немає у Safari. Перемикач «Офлайн-резерв Apple» не показується. |
| ШІ-озвучення книжки, пауза/стоп, підсвічування (R5) з відкритим екраном | ~90 % | Між реченнями можлива пауза в десятки мілісекунд більша, ніж в `AVAudioPlayer`. |
| Озвучення у фоні / із заблокованим екраном | ~30–60 % (ризик) | Залежить від поведінки WebKit; перевіряється на iPad. |
| Системний (офлайн) голос | ~75 % | `speechSynthesis`: набір голосів залежить від iPadOS, пауза/продовження в Safari працюють ненадійно (може починатися з початку речення). |
| Повтор вимови без повторного синтезу (G5, G6) | 100 % | Кеш MP3 у Cache Storage за тим самим SHA-256. |
| Зовнішні словники (DT2) | ~80 % | Сторінки словників не можна вбудувати (iframe заборонений сайтами); у встановленій PWA посилання відкриваються в системному вікні Safari — перемикач «Відкривати всередині застосунку» втрачає сенс. |
| Збережене, пошук, підсвічування слів, експорт CSV (Z1–Z7) | ~95 % | «Поділитися» через Web Share API з файлом; без нього — завантаження файла. |
| Тренування, вправи 1–4, клавіші (T1–T14) | ~95–100 % | Esc/Return із клавіатури працюють у Safari напряму. |
| Вправа 5 «Вимова» (P5-1–P5-4) | ~80 % | Системний текст дозволу не налаштовується; можливі особливості маршрутизації звуку. |
| Ключ, приватність | ~70 % | IndexedDB замість Keychain (див. ризики). |
| Вигляд: навігація, аркуші, перемикачі, іконки | ~85 % | Схожий на iPadOS, але не піксель у піксель: інші іконки, власні аркуші й анімації, немає системних жестів «назад» (у PWA потрібна кнопка «Назад»). |

**Підсумок.** Функціонально PWA повторює приблизно **90 %** нативного застосунку; повністю втрачається одна група (офлайн-переклад Apple), під ризиком дві (читання вголос у фоні й вправа «Вимова»), слабшає захист ключа. Візуально PWA впізнавано та сама програма (≈85 %), але не піксельна копія. Взамін PWA дає роботу без Xcode, на будь-якому пристрої з сучасним браузером, і миттєві оновлення.

## Рішення

**Продовжити** — головна цінність (читання з ШІ-перекладом над текстом, картки слів, ШІ-озвучення, збережене й тренування) переноситься майже повністю, а відмінності відомі заздалегідь і мають пом'якшення. Свідомі відхилення й питання C1–C8 погоджено користувачем 2026-10-21 (`spec.md` → «5. Уточнення»); головна умова — дизайн не гірший за нативний і застосунок повністю виконує функцію.
